# Operators, Operands and Expressions

## Operators

Special symbols that perform specific operations on one, two, or three operands that return a result.

### Equality Operator

Compares two operands

### Logical AND operator &&

Both sides of the if statement are true

### Logical OR operator ||

### Logical bitwise operator & or |

### instanceof

## Operand

Any object that is manipulated by an operator.

### Abbreviations

- ++ - increment by one
- -- - decrement by one

- += - compound assignment operator
- -= - compound assignment operator
- \/\*=
- /=

## Expression

Formed by combining variables, literals, method return values and operators.

```java
// [data type] [variable name] [= assignment operator] Expression
String myStr = "how " + "are " + "you?";
```
