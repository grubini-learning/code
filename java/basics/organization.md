# Organization

## Package

Namespace that organizes a set of related types. In general a package corresponds to a folder. They let us reuse common class names across different libraries or applications.

### Practices

- package names in all lowercase
- use reverse domain name to start package naming conventions
  - Example for abccompany.com: `com.abccompany`

## Imports

- Have to be declared before classes, but after packages
