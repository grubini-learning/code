# Class

Custom data type or a special code block that contains methods.

- a template for creating objects.

## Attributes or Fields

Variables for classes that are carried with the lifespan of the specific object.

- static fields: aren't changing constantly nd does not need for the class to be instantiated to be used.

## Default values for fields

- boolean - false
- 0
  - byte
  - short
  - int
  - long
  - char
- 0.0
  - double
  - float

## Constructor

Function that sets values of object's attributes in instantiation and perform init logic

## Getter methods

A way to enforce encapsulation and obtaining data that is private in a class

## Setter methods

Allow to set values in private fields of a class

## Object

Is an instance of a class.

- the `new` keyword creates an instance of a class
