# Keywords

Reserved words that have predefined meaning for Java.

## class

used to define a class

- method
  - collection of statements that perform an operation

## static

## void

## this

Refers to the instance that was created

## var (introduced in JAVA 10)

Contextual keyword that declares a local variable type inference. By using var we are telling Java compiler to figure out the compile time type for us.

### Cant's

- be used in field declarations on a class
- used in method signatures, either a param or return type
- used without an assignment because the type can't be inferred
- assign a null literal because a type can't be inferred
