# Which Version of Java

## What is LTS

Long Term Support, these receive updates from Oracle for years

## Reasons to choose and LTS version

- stability
- support
- ecosystem: libraries, tools and frameworks often focus their support on LTS versions

## Install LTS

- type in java.sun.com
